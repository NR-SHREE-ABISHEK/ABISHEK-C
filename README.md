# ABISHEK-C
This repository contains C programs written for learning and practice. It focuses on understanding core concepts and logic building. All programs are simple, clear, and beginner-friendly. Created as part of academic and self-learning practice.

📌 Mini CRM System (C)


This is a console-based Mini CRM system developed using C programming to manage customer records efficiently. The project simulates basic real-world customer management operations with a simple and structured design. It focuses on strengthening core programming logic and data handling concepts.

*Implemented add, search, update, and delete customer features.

*Used structures for organized data storage.



📌 ATM Simulation System (C)


This project is a console-based ATM simulation developed using C programming. It allows users to securely log in using a PIN and perform basic banking operations like checking balance, depositing money, withdrawing money, and viewing transaction count. The project demonstrates strong understanding of functions, conditional statements, loops, and basic financial logic implementation.

*Implemented secure PIN authentication with limited attempts.

*Used functions and global variables to manage balance and transactions efficiently.limited attempts.
